Automatic window tiling for KDE Plasma

Make room for what’s next.

Open a window and ktiler rearranges the others to make space. It’s a free, open-source KWin script for the Plasma desktop you already use.

Install ktiler Try in your browser

For KDE Plasma 6.3 or newer on Wayland, including Kubuntu 26.04 LTS.

Choose how windows fit

Put apps side by side, stack them, or split the screen into panes. Drag a shared edge to give one window more space.

Move a window to the next screen

Use Alt + Shift with a direction key to swap windows. At a screen edge, the same shortcut moves the window to the next display in that direction. You can change any shortcut.

  • W Up
  • A Left
  • S Down
  • D Right

Install ktiler

Requires KDE Plasma 6.3 or newer in a Wayland session. Check compatibility.

Install from a terminal

Recommended

The installer backs up existing settings and adds ktiler Settings to your app launcher. It checks your Plasma session and looks for other tilers and shortcut conflicts before enabling ktiler.

It also adds a system tray toggle: see whether tiling is on or paused, and click to switch.

Enabling ktiler can rearrange your open windows. Run without sudo:

Terminal
❯ 
curl -fsSL https://ktiler.org/install.sh | sh
Read the installer script

Install from File

No terminal needed. This installs ktiler without the tray toggle. To change settings, use Configure in KWin Scripts.

Updating from a file? Restore or pause ktiler, then untick it in KWin Scripts and click Apply before installing the update.

  1. Download ktiler.kwinscript.
  2. Open System Settings and search for KWin Scripts.
  3. Choose Install from File and select the download.
  4. Tick ktiler and click Apply to start tiling.
