Click a display or window to activate it. Drag display titles to arrange screens; drag shared window edges to resize tiles.

For rows and columns, select the window whose edge you want to resize. Spread resize shares the adjustment across windows beyond that edge.

Alt + + / −
Add / remove selected window
Alt + B / V / H
Binary / vertical columns / horizontal
Alt + arrows
Select a neighboring window
Alt + Shift + arrows
Swap; cross displays at an edge
Alt + Shift + R
Rotate clockwise
Alt + Shift + E
Rotate counterclockwise
Alt + 1–9 / 0
Activate display 1–9 / 10

Desktop shortcuts take precedence. Use the buttons or change Keys.
