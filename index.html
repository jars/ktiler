Automatic window tiling for KDE Plasma

Make room for what’s next.

Open a window and ktiler rearranges the others to make space. Keep the Plasma desktop you already use.

Install ktiler Try in your browser

For KDE Plasma 6 on Wayland, including Kubuntu 26.04 LTS.

Choose how windows fit

Put apps side by side, stack them, or split the screen into panes. Drag a shared edge to give one window more space.

Move a window to the next screen

At the right edge of one display, press Alt + Shift + D to move a window to the display on its right. You can change any shortcut.

Try moving a window in the simulator

Install from System Settings

One script file. No terminal, compiler, or extra plugin needed.

Download ktiler Check compatibility
  1. Download ktiler.kwinscript.
  2. Open System Settings and search for KWin Scripts.
  3. Choose Install from File, select the download, then tick ktiler and click Apply.
