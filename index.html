Open a window and ktiler rearranges the others to make space. Keep the Plasma desktop you already use.

Choose how windows fit

Put apps side by side, stack them, or split the screen into panes. Drag a shared edge to give one window more space.

Move a window to the next screen

Use Alt + Shift with a direction key to swap windows. At a screen edge, the same shortcut moves the window to the next display in that direction. You can change any shortcut.

  • W Up
  • A Left
  • S Down
  • D Right

Install ktiler

Requires KDE Plasma 6.3 or newer in a Wayland session. Check compatibility.

Install from a terminal

Installs ktiler, its branded icon, and a ktiler Settings entry in your Application Launcher. Run as your regular user, without sudo:

curl -fsSL https://ktiler.org/install.sh | sh

Read the installer script.

Install from File

No terminal needed. This option uses a KDE theme icon. To change settings, use the Configure button in KWin Scripts.

  1. Download ktiler.kwinscript.
  2. Open System Settings and search for KWin Scripts.
  3. Choose Install from File and select the download.
Download ktiler

Updating? Restore or pause ktiler, then untick it in KWin Scripts and click Apply before installing the update.

After either install: Open System Settings → KWin Scripts, tick ktiler, and click Apply. ktiler starts arranging eligible windows once enabled. If it isn’t listed, close and reopen System Settings.
